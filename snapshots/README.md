# snapshots/

**Point-in-time assessments — NOT maintained documentation.**

Each file here records the state of something (deployment, data, environment) on
a specific date. They are dated and intentionally *not* updated afterward: a
snapshot describes how things were at that moment, and the real system may have
changed since. Read the date first. If you need current state, re-check the
system directly rather than trusting an old snapshot.

For enduring documentation (how things *should* work), see the repo's `README`,
`PLAN.md`, `STEPS.md`, and `DECISION_LOG` instead.
